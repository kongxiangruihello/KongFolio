# KongFolio 0.3

原生 macOS 个人文档工作台。SwiftUI / AppKit + PDFKit + Core Image + Vision + Core Graphics，全程本地处理，无第三方依赖。

## 运行

双击同级 `KongFolio.app`，或解压 `KongFolio-0.3-macOS.zip` 后打开应用。本次提供 Apple Silicon 本机构建；最低目标 macOS 14。开发包使用本地 ad-hoc 签名，尚未正式公证。

```sh
./scripts/build.sh
open ../KongFolio.app
```

支持 Command Line Tools 构建，也可以用完整 Xcode 打开 `Package.swift`。

## 0.3 新增

### 鼠标选择裁剪

1. 打开图片（也可将 PDF 页面切换到 Image）。
2. 点击右侧“鼠标选区裁剪”，在图片上拖出矩形。
3. 拖动八个边角控制点改变大小；在框内拖动可移动选区。框外变暗，底部显示工作图中的像素尺寸。
4. 点击“确认裁剪”生成预览，或“取消裁剪”保留原来的调整。
5. 点击“应用到页面”，然后从“导出”选择格式。应用操作支持撤销/重做，也可恢复原始页面。

可在已裁剪图片上继续框选；新选区与先前参数组合。裁剪后的 PDF 页面按实际选区缩小，不放大回原尺寸。原图开关、切换页面或退出裁剪模式会取消尚未确认的选区。未确认的框不保存；确认后的调整可随项目保存。

### 阅读、摘录与 OCR

- 左侧导航切换页面 / 目录 / 书签 / 搜索 / 摘录；读取 PDF 内嵌目录，自定义书签随项目保存。
- 连续、单页、双页阅读，保存当前页、阅读位置与缩放。页面操作同步调整书签和目录对应页。
- 搜索结果包含页码和上下文，点击跳转；最多列出 1000 处匹配。
- 高亮时附加右侧笔记；摘录列表显示原文、笔记和页码，单独导出 Markdown 摘要。
- OCR 区域检查显示识别框、文本和置信度，点击文本或框线联动高亮。检查本身不改变 PDF 文本。
- 0.3 中执行过 OCR 的页面可从保存的 OCR 前页面重新识别，避免重复叠加文本；后加标注会被替换，执行前提示，操作可撤销。区域检查暂不直接编辑识别文字。
- 0.3 项目格式向后读取 0.2 项目；新保存项目不能在 0.2 中打开。

### 导出与响应速度

- PDF / PNG / JPG / TIFF 可选全部、当前或选中页面。
- 普通 PDF 保留原始页面内容和可编辑标注；图片型 PDF 可指定 DPI 与 JPEG 质量，保留物理尺寸，但文字、链接和标注固化。
- 图片导出支持 72 / 150 / 300 / 600 DPI，显示当前页像素尺寸；每页最多 8000 万像素、单边最多 20000 像素。
- 可估算体积：普通 PDF 按实际序列化大小；图片按最多前三页采样，图片型 PDF 仅作近似参考。
- 缩略图按需后台渲染，使用有限缓存；文件读取解析和项目写入移到后台；未改变的文档复用序列化快照。
- 仍有主线程页面装配、快照初次序列化和图片预览步骤，尚未完成超大文件压力验证。

## 0.2 新增

### 保存与恢复

- ⌘S 保存 `.kongfolio` 项目；⇧⌘S 另存项目，⌘E 导出 PDF。
- 项目保存页面、标注、页面选择、原始图片页面、已应用参数和未应用的图片调整。
- 编辑后约 0.7 秒自动保存恢复副本，启动时恢复；关闭时同步保存恢复状态。
- 关闭或替换有修改的文档时可选择“保存项目 / 取消 / 放弃修改”。
- “打开”菜单包含最近 12 个文件或项目。
- 自动恢复副本与最近列表存放于 `~/Library/Application Support/KongFolio/`。恢复副本只有最近一个工作区；不会自动覆盖导入文件或已保存项目。手动保存项目用于长期保留或迁移。

### 页面管理

- ⌘点击多选、⇧点击连选，或输入 `1–3, 5, 8–10` 选择页码。
- 拖动缩略图放在目标页之前；上下按钮整体移动选中页。
- 批量复制、旋转、删除、提取及逐页拆分；文档至少保留一页。
- 多文件导入前可调整文件顺序。插入后自动选中新页面。
- 撤销/重做保留最多 20 步，并按约 192 MB 的快照估算收缩历史；单个大快照可能超过此值。重启后保留当前工作状态，不保留撤销历史。

### 图片与扫描件

- 框选裁剪、±15°倾斜校正、90°旋转、水平翻转。
- 自动识别纸张四角并校正透视；识别失败会提示，可改用框选裁剪和倾斜校正。
- 亮度、对比度、饱和度、锐化、黑白、扫描增强。
- “原图”开关对照原始内容；项目保留原始页面及参数，可重新调整或恢复原始页面。
- 点击“应用到页面”更新文档。项目可保存未应用调整；导出前需先应用。
- 图片处理使用原始页面最长边约 3000 像素的工作图。保留的原始页面不降采样，但处理后导出页受此分辨率限制。

### 标注和签名

- 高亮、批注、文字框、画笔、箭头、手写签名。
- 选择“编辑标注”后点击并拖动标注；也可在右侧当前页标注列表中选择。
- 选中后支持修改文字、颜色、放大/缩小和删除，可撤销。
- 签名库保存当前页通过“签名”工具绘制的全部笔画，插入时放到页面中央，再用编辑标注工具移动。
- 签名库只保存在本机，不是证书数字签名，不随项目一起迁移。

### OCR 与后台任务

- OCR 支持全部页面或选中页面；识别中英文并跳过已有文本页。
- OCR 用渲染图识别，但输出时保留原 PDF 页面内容并叠加真正不可见文本层，避免整页重新降采样；已有标注会固化。
- OCR、压缩、批量图片导出和拆分在后台执行，提供进度、取消与失败重试。
- 一次运行一个任务。取消通常在当前页完成后生效；OCR 取消不提交部分修改；批量导出先写临时目录，成功后统一发布，取消清理临时输出。
- 重试保留上次任务的输入快照；OCR 文档发生修改后需重新发起。

## 原有能力

打开 PDF、JPG、PNG、HEIC、TIFF（含多帧），PDF 阅读、文本搜索、缩略图导航、缩放、PDF/图片合并。导出 PDF、JPG、PNG、TIFF、TXT、Markdown，全文批量 PNG。

Quick Tools 包括 Merge PDFs、Compress PDF、OCR PDF、Images → PDF、PDF → Images、Scan Document、Sign PDF、Compare PDFs。

## 当前边界

- Scan Document 为导入扫描件，不连接相机或物理扫描仪。
- Compare PDFs 为双栏人工比对，暂不自动检测差异。
- 压缩为降采样 JPEG 栅格副本，文本与标注固化，不保证每种文件都会缩小。
- 重新应用图片参数会替换当前页，包括其后加入的文本层和标注；原始页面保留，可撤销或恢复。PDF 标注仍属于页面内容，不随图片透视参数独立重排。
- 页码范围按文档自然顺序去重；拆分目前每页一份 PDF。
- 导入后的页面装配、项目快照初次序列化和图片预览仍有主线程步骤；超大文档可能短暂等待。自动保存是防抖快照，不保证突然断电时保留最后一秒的操作。
- 项目文件含嵌入式 PDF 与原始页面，可能比导出 PDF 大；项目未加密。
- 不支持原始 PDF 文本重排、Word/Excel 解析、密码 PDF、证书签名、云同步、AI 问答。
- Apple Silicon 本机已验证；Intel、旧版 macOS、大文档压力测试及正式分发仍需后续验证。

## 架构

| 模块 | 职责 |
| --- | --- |
| KongFolioApp | 应用生命周期、单窗口、菜单与关闭保护 |
| Workspace | 工作状态、撤销、多页操作、导入导出与图片配方 |
| ProjectStore | 版本化项目归档、串行原子恢复写入、页码范围解析 |
| BackgroundJobs | 后台 PDF 任务、进度、取消、临时输出提交 |
| DocumentServices | 图像处理、Vision OCR/纸张检测、PDF 文本层 |
| PDFCanvas / AnnotationEditing | PDFKit 画布、标注交互、签名库 |
| ContentView / ImageCanvas / CropGeometry | 三栏界面、Quick Tools、鼠标裁剪和坐标变换 |
| ReadingServices / ReadingSidebar | 目录、书签、文本搜索、摘录、阅读状态 |
| ExportServices / ExportSheet | DPI、格式、范围、估算与后台导出 |
| ImportServices / ThumbnailView | 后台读取、按需缩略图和缓存 |
| OCRReview | 识别区域、文本与置信度对照 |
